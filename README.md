## 📌 О проекте

**«Школа.Синхрон»** — это комплексный образовательный сервис и чат-бот для мессенджера MAX, автоматизирующий взаимодействие между учителями и учениками. Бот превращает рутинные образовательные процессы в интерактивный и удобный цифровой опыт.

### 🌟 Ключевые возможности:

1. **👨‍🏫 Кабинет учителя:**
   * **Генерация квизов и тестов по материалам:** загрузка учебных файлов (PDF, DOCX) с мгновенным извлечением текста и генерацией интерактивных тестов с помощью нейросетей (GLM-5.3-Flash / GLM-5.3).
   * **Управление классами и выдача ДЗ:** генерация уникальных кодов подключения (с кнопкой быстрого копирования в буфер обмена `ClipboardButton`), публикация домашних заданий и заметок с авто-привязкой к расписанию.
   * **Аналитика успеваемости:** отслеживание прохождения тестов учениками в реальном времени.

2. **👨‍🎓 Кабинет ученика:**
   * **Актуальное расписание лицея:** встроенная база расписания 34 классов Лицея № 44 на 5-дневную учебную неделю (пн-пт). В выходные дни бот автоматически показывает расписание на предстоящий понедельник.
   * **Трекер задач и домашних заданий:** интерактивный список задач с переключением статуса по нажатию кнопки («✓ Выполнено» / «✗ В процессе»).
   * **Интерактивные викторины:** прохождение тестов по коду квиза или привязанных к классу прямо в интерфейсе MAX с подсчетом баллов.

3. **⏰ Утренний синхронизатор (07:00 MSK):**
   * Ежедневная утренняя рассылка по будням (пн-пт): актуальные уроки на день, невыполненные домашние задания и вдохновляющая цитата дня.
   * Автоматическая защита от спама (rate limit 0.55 сек между сообщениями) и фильтрация уже обработанных уведомлений.
   * Панель администратора: команда принудительной рассылки `/morning_test` (доступна ID администратора: `43359625`).

4. **🛡️ Отказоустойчивый прокси-шлюз (Failover Proxy):**
   * Встроенный OpenAI-совместимый шлюз на FastAPI (`proxy_server.py`), обеспечивающий прозрачное переключение между моделями при таймаутах, ошибках сети или лимитах (HTTP 429 / 5xx).

## 📂 Структура репозитория

```text
├── core/                         # Ядро бизнес-логики и сервисов
│   ├── ai_work.py                # Генерация квизов, валидация JSON и очистка HTML для MAX
│   ├── config.py                 # Конфигурация клиента LLM (OpenAI SDK / Reformboss)
│   ├── database.py               # Асинхронная БД SQLite (пользователи, классы, задания, квизы)
│   ├── file_parser.py            # Безопасный парсинг PDF и DOCX с проверкой magic bytes
│   ├── morning_notifications.py  # Планировщик утренних рассылок (07:00 MSK, 5-дневка)
│   └── schedule_parser.py        # База расписания Лицея № 44 (34 класса, пн-пт)
├── max_bot/                      # Модуль бота для MAX Messenger
│   └── main_bot.py               # Обработчики событий MAX (сообщения, колбэки, клипборд, deep links)
├── tests/                        # Набор модульных тестов
│   └── test_quiz_generator.py    # Тестирование генерации квизов и схем Pydantic
├── proxy_server.py               # Локальный отказоустойчивый прокси-сервер (порт 8000)
├── entrypoint.sh                 # Скрипт одновременного запуска прокси и бота в контейнере
├── Dockerfile                    # Спецификация сборки Docker-образа
├── docker-compose.yml            # Конфигурация запуска через Docker Compose
├── requirements.txt              # Список зависимостей с описанием библиотек и версий
├── Requierments.txt              # Алиас файла зависимостей по требованию регламента конкурса
├── .env.example                  # Пример конфигурации переменных окружения
├── .dockerignore                 # Исключения для сборки Docker-образа
└── README.md                     # Документация и инструкция по запуску
```

## ⚙️ Настройка переменных окружения

Перед первым запуском создайте файл конфигурации `.env` на основе примера `.env.example`:

```bash
cp .env.example .env
```

Заполните ключевые переменные в файле `.env`:

```ini
# ========================================================
# Платформа MAX Messenger
# ========================================================
BOT_TOKEN=ваш_токен_бота_max
BOT_LINK=https://max.ru/ideya_fiks_136_bot
BOT_NAME=ideya_fiks_136_bot
ADMIN_ID=43359625

# ========================================================
# Настройки нейросети (OpenAI-совместимый API)
# ========================================================
API_KEY=ваш_api_ключ
BASE_URL=https://api.reformboss.com/v1
MODEL=zai-org/GLM-5.3-Flash
FALLBACK_MODEL=zai-org/GLM-5.3

# ========================================================
# Настройки встроенного прокси-шлюза (proxy_server.py)
# ========================================================
UPSTREAM_BASE_URL=https://api.reformboss.com/v1
UPSTREAM_API_KEY=ваш_api_ключ
TARGET_MODEL=zai-org/GLM-5.3-Flash
PORT=8000
FORCE_DEFAULT_KEY=false
```

## 🚀 Инструкция по запуску

Вы можете запустить проект любым удобным способом: через **Docker**, **Docker Compose** или **напрямую из командной строки**.

### Способ 1. Запуск через Docker Compose (Рекомендуемый)

Docker Compose автоматически собирает контейнер, подключает том для сохранения базы данных SQLite (`school_sync.db`) и пробрасывает порт прокси-сервера:

```bash
# Сборка и фоновый запуск контейнера
docker compose up --build -d

# Просмотр логов в реальном времени
docker compose logs -f

# Остановка контейнера
docker compose down
```

---

### Способ 2. Сборка и запуск через чистый Docker

#### 1. Сборка Docker-образа:
```bash
docker build -t school_sync_bot .
```

#### 2. Запуск контейнера:
```bash
docker run -d \
  --name school_sync_app \
  --restart unless-stopped \
  -p 8000:8000 \
  --env-file .env \
  -v $(pwd)/school_sync.db:/app/school_sync.db \
  school_sync_bot
```

#### 3. Управление контейнером:
```bash
# Просмотр логов
docker logs -f school_sync_app

# Остановка
docker stop school_sync_app

# Удаление
docker rm school_sync_app
```

---

### Способ 3. Запуск через командную строку (Local CLI)

#### На Linux / macOS:

1. **Создание и активация виртуального окружения:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. **Установка зависимостей:**
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

3. **Запуск отказоустойчивого прокси-сервера (терминал 1):**
   ```bash
   PORT=8000 python proxy_server.py
   ```

4. **Запуск бота MAX Messenger (терминал 2):**
   ```bash
   source .venv/bin/activate
   PYTHONPATH=. python -m max_bot.main_bot
   ```

#### На Windows (PowerShell):

1. **Создание и активация виртуального окружения:**
   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

2. **Установка зависимостей:**
   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

3. **Запуск прокси-сервера (терминал 1):**
   ```powershell
   python proxy_server.py
   ```

4. **Запуск бота (терминал 2):**
   ```powershell
   $env:PYTHONPATH="."
   python -m max_bot.main_bot
   ```
